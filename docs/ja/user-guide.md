# ユーザーガイド

ShinkiEMU Manager の日常的な使い方を解説します。初めて導入する場合は先に[クイックスタート](quick-start.md)をご覧ください。

## 表示言語と外観

**設定 → 外観 → 言語**から日本語・英語・簡体字中国語へ即時切り替えできます。「システムに従う」は OS ロケールに合わせて自動選択します。Manager には日本語・中国語フォントが同梱されており、日本語表示時は日本語字形で描画されます。ライト／ダークテーマおよびカスタムアクセントカラーに対応しています。

## Manager のアップデート確認

通信許可時、起動ごとにバックグラウンドで新バージョンを静かに確認します（オフライン時にエラーポップアップは出しません）。**設定 → アップデート**から手動確認も可能です。更新は `Project-Shinkirou/ShinkiEMU` の GitHub Releases を参照し、ブラウザのダウンロードページを開きます（自動上書きは行いません）。

## ライブラリとコア管理

### ローカル作品のスキャン

**設定**から正当に入手したゲームのディレクトリを追加しスキャンします。暗号化アーカイブを扱う作品では、各コア設定からローカルの鍵ファイルを指定してください（鍵は端末外へ送信されません）。コア更新後、廃止された設定項目は自動整理されます。

### デスクトップ版コアの導入と更新

1. **設定**でネットワーク通信を許可します；
2. **コア**画面でカタログを更新します（バージョン・ABI・URL・SHA-256 を検証）；
3. 必要なコアをインストールまたは更新します。

読み込み済みコアを更新する場合は、実行中のゲームを終了してから案内どおり Manager を再起動してください。コアフォルダ内の `core.json`、依存ライブラリ、`Resources/`、`licenses/` は一式まとめて保持してください。

## ストアダウンロード（Steam / DLsite / DMM）

**ゲームを追加 → ストアダウンロード**から、所有済みの PC 版作品を直接ライブラリへダウンロードできます。Cookie やリフレッシュトークンは OS の安全な資格情報ストア（Windows 資格情報マネージャー、Linux Secret Service、macOS/iOS キーチェーン、AndroidKeyStore）のみに保存され、ログアウトで削除されます。

### Steam

- **ログイン**：パスワード＋Steam Guard、モバイルアプリでの QR コードスキャン、デスクトップ版でのローカル Steam クライアント認証取り込みに対応。
- **ダウンロードと修復**：デポ（モバイルでも互換性のため標準で Windows デポを選択）とブランチを指定可能。**更新確認**（差分再利用）と**検証と修復**に対応しているため、ゲームフォルダ内の `.DepotDownloader` を残してください。

### DLsite・DMM GAMES / FANZA

- **Web ログイン**：OS 標準 WebView（WebView2 / WKWebView / WebKitGTK / Android WebView）のプライベート一時領域で公式ログイン画面を開き、CAPTCHA や 2 段階認証をそのまま通過できます。ログイン完了後はセッション Cookie を自動取得し一時領域を破棄します。
- **DLsite**：DLsite Play の購入済み PC 版ファイルのみをダウンロードします。ZIP はパス安全性検証後に自動展開し、RAR やインストーラーは手動実行用としてそのまま保持します。
- **DMM GAMES / FANZA**：現在はログインのみ対応しています。

新規ストア導入先は `<ライブラリルート>/.shinki/store/<ストア>/installs/` です。Manager はストアの DRM やライセンス認証を回避・除去しません。

## 互換性とメタデータ同期

標準メタデータソースは `https://project-shinkirou.github.io/data/shinkiemu/v1/` です。破損または検証失敗のスナップショットは有効なキャッシュを上書きしません。互換性レポートを参照する際は **VNDB リリース rID・コア・プラットフォーム・アーキテクチャ・desktop/device/simulator 区分**を合わせて確認してください。

## Luau パッチ

**パッチ**画面ではレビュー済みの**オンラインパッチ**（VNDB リリースとファイル指紋 SHA-256 に紐付け）とローカル `.luau`/ZIP（未レビュー表示）を同一サンドボックスで実行します。許可された HTTPS ダウンロードはサイズと SHA-256 を検証し `<game>/.shinki/patch/` にキャッシュします。EXE の追加・改変は禁止されています。

- **新規フォルダ出力（標準）**：選択した親フォルダ配下の `localized-output` へ出力し、元フォルダは変更しません。
- **上書き適用**：一時領域で処理したうえで変更・削除される元ファイルを `<game>/.shinki/backup/<id>/` にバックアップし、**直前のパッチを復元**できます。

> [!TIP]
> 一部のパッチは新しいコア機能（例：新 Musica パッチは Musica `beta.5` 以降）を必要とします。更新案内が表示された場合は**コア**画面から更新後に再実行してください。

## データフォルダと原版セーブ互換

ShinkiEMU がゲームフォルダ内に書き出すファイルはすべて `<game>/.shinki/` 以下に格納されます。アプリデータフォルダは**設定**から開け、デスクトップでは `SHINKI_EMU_DATA_DIR` で指定できます。

- **外部コア**：アップストリームのセーブ場所・形式をそのまま維持します。
- **Shinki Musica**（`shinki.emu.musica`）：`<game>/.shinki/musica/minori/<title>/` で原版互換の `.sav` / `.png` を直接読み書きでき、Windows 原版の `Documents\minori\<title>\` と相互コピー可能です（[Musica コア説明](cores/shinki-emu-musica.md)）。

セーブのバックアップや移行を行う前に、必ずゲームを終了してください。
