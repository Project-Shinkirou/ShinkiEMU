# ShinkiEMU Manager 0.1.0-beta.6

Musica の手動セーブ、クイックセーブ、オートセーブは、eden/Perseus 本来の `.sav` スロットと対応する `.png` サムネイルを使用します。旧ベータ版の `.asav` ファイルとは互換性がなく、旧ディレクトリにそのまま残します。読み込み、変換、移動、削除は行いません。

Musica は Android と実験的な OHOS に加え、実機ターゲットと両シミュレーターターゲットの iOS Manager に静的に組み込まれます。iOS では動的コアの単独インストールをサポートしません。統合リリースには、その exact-head でのビルド、パッケージ、署名、ネイティブ依存関係、対応ソースの確認が必要です。独立した移植版の結果は統合版の確認を代替しません。

OHOS HAP は引き続き実験的な OpenHarmony SDK テスト PKI 署名パッケージです。デバイス、エミュレーター、ゲーム、アカウントの起動確認は免除されており、市販デバイスへのインストール可能性は未確認です。公開する各プラットフォームのパッケージには対応ソースと依存ライブラリの通知を添付します。公開済み Manager beta4 と beta5 の成果物は変更しません。
