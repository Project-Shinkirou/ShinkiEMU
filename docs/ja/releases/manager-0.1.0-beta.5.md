# ShinkiEMU Manager 0.1.0-beta.5

既存の Manager プラットフォームに加え、実験用の OHOS arm64 HAP を追加します。Slint 管理画面と OpenHarmony のネイティブウィンドウ、入力、音声、WebView ホストを統合しています。

HAP は OpenHarmony SDK のテスト PKI で署名しており、製品用証明書ではありません。ローカル DevEco で署名とネイティブ依存関係を確認し、ホスト側の引き渡しゲートで実際の HAP と対応ソースの SHA256、パッケージ内容、ネイティブ依存関係、ソースのコミットを照合します。デバイス・エミュレーターの起動確認は免除されており、市販デバイスへのインストール可能性は未確認です。

ホストされたプラットフォームは既存のリリースゲートを維持します。Android のユニバーサル APK はリリース鍵で署名します。各公開プラットフォームに対応ソースと依存ライセンスを提供します。beta4 のリリースと添付ファイルは変更しません。
